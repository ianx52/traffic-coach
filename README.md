# 流量教练 · 自媒体流量诊断 Skill

> 不讲课，给判断。给我文章，我告诉你发不发；给我数据，我告诉你卡在哪。

一个面向今日头条图文创作者的 AI Skill，解决两个核心问题：

1. **发布前把关**：审核写好的头条文章，判级"可发 / 小改 / 中改 / 别发"
2. **发布后诊断**：根据内容和账号数据，定位流量瓶颈并给出可执行动作

## 核心引擎

- **文章审核引擎**：发布前判级（4级）+ 一页8项清单（标题/开头/结构/长度/互动/关键词/合规/垂直）
- **单篇内容诊断决策树**：点击率 → 完读率 → 互动率 → 搜索 逐层定位瓶颈
- **账号增长漏斗**：曝光 → 消费 → 主页访问 → 关注 → 留存 找出漏损层
- **目标现实性校验**：日增粉需求 vs 历史天花板，给分层预期
- **硬触发复盘规则**：连续N篇低于基线→砍类型，不靠感觉
- **迭代赢家机制**：爆款→变体→测试，一次只改一个变量

## 安装

**方式一：让 Agent 安装**

在支持 Skill 的会话中说：

```
帮我安装这个 skill：https://github.com/ianx52/traffic-coach
```

**方式二：手动安装**

```bash
git clone https://github.com/ianx52/traffic-coach.git
# 将 traffic-coach/ 目录放入你的 Skills 目录
```

## 使用

触发词：「流量教练」+ 你的情况/数据/问题/文章

```text
流量教练，帮我看这篇头条文章行不行（附文章）
流量教练，我阅读量卡在3000推不动，数据是……（附数据）
流量教练，我账号为什么不涨粉（附账号数据）
流量教练，我想两周涨5000粉，现实吗
```

### 审核输出示例

```text
【判级】✅可发 / ⚠️小改 / 🔧中改 / ❌别发
【一句话理由】……
【必改项】最多3条
【这文章最值钱的地方】……
```

## 边界声明

- **数据基准**：2026年8月今日头条新版算法，具体数字集中在 `references/algorithm.md`，**会过期，建议每季度复核**（方法论在 SKILL.md，不随算法变）
- 覆盖范围：今日头条图文为主，兼顾微头条；不覆盖短视频、直播、其他平台
- 本 Skill 不教赛道选择、不教变现、不重写全文
- 所有建议均附带验证方法，请用真实数据验证后再做决策
