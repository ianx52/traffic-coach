# 流量教练 · 自媒体流量诊断 Skill

> 不讲课，给判断。给我内容，我告诉你发不发；给我数据，我告诉你卡在哪。

**薄通用内核 + 平台模块架构**：一个 skill 装给头条/抖音等多个平台的 agent，各自调用需要的平台模块。方法论共享（通用层），判断各自独立（平台层）。

当前支持：
- **今日头条**图文/微头条（完整模块）
- **抖音口播**脚本（完整模块，2026算法重构版）
- **公众号**（完整模块，2026订阅+算法双引擎版）

## 核心引擎

- **审核引擎**：发布前判级（4级）+ 一页8项清单（钩子/开头/结构/长度/互动/关键词/合规/垂直）；给判断和代价、留选择权（红线除外）
- **平台路由**：先问"你在哪个平台"，加载对应平台模块（头条/抖音/公众号）
- **单篇内容诊断决策树**：点击 → 消费 → 互动 → 搜索 逐层定位瓶颈
- **背离诊断**：两两指标打架一眼定位（曝光高+点击低=钩子；点击高+完读低=内容；完读高+互动低=选题）
- **账号增长漏斗**：曝光 → 消费 → 主页访问 → 关注 → 留存 找出漏损层
- **目标现实性校验**：日增需求 vs 历史天花板，给分层预期
- **硬触发复盘规则**：连续N条低于基线→砍类型，不靠感觉；附数据低谷期操作清单
- **迭代赢家机制**：爆款→变体→测试，一次只改一个变量
- **置信度与样本量**：报告标注高/中/低置信度，样本不足只给方向不下死结论
- **平台利益逻辑**：每个平台模块解释"算法为什么这样设计"，理解意图→预判变化
- **账号基线系统**：平台基准 vs 账号自身基线双参照，建议对错用数据验证（反馈自校准）
- **选题引擎**：好选题三关 + 四路来源（爆款拆解/评论区/搜索词/垂直热点），只挑毛病不代选

## 安装

**方式一：让 Agent 安装**

在支持 Skill 的会话中说：

```
帮我安装这个 skill：https://github.com/ianx52/traffic-coach
```

**方式二：手动安装**

```bash
git clone https://github.com/ianx52/traffic-coach.git
# 将 traffic-coach/ 目录放入你的 Skills 目录
```

## 使用

触发词：「流量教练」+ 平台 + 你的情况/数据/问题/内容

```text
流量教练，头条，帮我看这篇头条文章行不行（附文章）
流量教练，抖音口播，帮我看这段口播脚本（附脚本）
流量教练，头条，我阅读量卡在3000推不动，数据是……（附数据）
流量教练，抖音口播，我账号为什么不涨粉（附账号数据）
流量教练，我想两周涨5000粉，现实吗
```

### 审核输出示例

```text
【判级】✅可发 / ⚠️小改 / 🔧中改 / ❌别发
【一句话理由】……
【必改项】最多3条
【这内容最值钱的地方】……
```

## 边界声明

- **数据基准**：各平台数据在 `references/{toutiao,douyin,wechat}.md`，**会过期，建议每季度复核**（方法论在 SKILL.md/common.md，不随算法变）
- **质量原则**：通用层只放"三个平台都成立的判断"；平台专属数据各存各的，禁止跨平台换算（头条完读率≠抖音完播率）
- 覆盖范围：今日头条图文/微头条、抖音口播脚本、公众号文章
- 本 Skill 不教赛道选择、不教变现、不重写全文
- 所有建议均附带验证方法，请用真实数据验证后再做决策
