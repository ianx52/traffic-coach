# 通用内容方法论 · 跨平台

> **本文件是"薄通用层"的内容部分**——所有平台都成立的内容判断和创作技巧。
> 不含任何平台的具体数字（那些在各平台模块）。一条规则只要有两个平台站不住，就放回各平台，不进本文件。
> 平台模块：`toutiao.md`（头条）/ `douyin.md`（抖音口播）/ `wechat.md`（公众号）

---

## 一、为什么需要这一层

流量教练的通用性来自这里：**判断内容的"底层好坏"不需要知道平台**——钩子强不强、结构清不清晰、互动钩子有没有，任何平台都一样。平台只决定**数字标准**（多少算好）和**分发机制**（怎么推）。

所以：
- **内容好不好** → 用本文件（通用）
- **数字达不达标** → 用平台模块（专属）

---

## 二、钩子（标题/开场）通用公式

钩子的任务是让用户**停下来**。所有平台通用，核心是制造"信息缺口"——让人想知道答案。

### 标题/开场钩子公式

| 类型 | 公式 | 例（头条/公众号） | 例（抖音口播） |
|------|------|-----------------|--------------|
| 数字反差 | 具体数字 + 反常识结论 | "15万人失业，谁在被重新定价" | "9名百万年薪高管，为130台服务器进了被告席" |
| 冲突 | 双方矛盾 + 悬念 | "老板一边裁员一边买AI" | "我们一边喊AI抢工作，一边用AI干活" |
| 身份共鸣 | 指向具体人群 + 利益 | "运营转AI运营3个月涨薪50%" | "做运营的，你的岗位正在被AI重写" |
| 威胁/机会 | 明确的失去或获得 | "你的AI工具迟早涨价" | "再不用AI，你的活就要外包了" |
| 疑问 | 具体问题 + 不剧透 | "为什么宁可坐牢也要运B300进中国" | "为什么你拍的口播没人看？" |

### 钩子三问（发布前自检）

1. 前几个字（标题前部/口播前3秒）有没有出现关键词或利益？
2. 有没有制造"信息缺口"（让人必须看下去才知道答案）？
3. 有没有夸大失实（有=标题党，会伤账号）？

**要钩子，不要夸张。** 钩子承诺的，内容必须兑现。

## 三、开头写法（首屏留存）

开头决定"消费率"（完读/完播）。所有平台通用：**开头不钩住，后面再好也白搭。**

### 开头三原则

1. **结果前置**：把最炸的结论/冲突放最前，不铺垫。
   - 差的："随着AI技术的快速发展……"
   - 好的："74台美国禁售的顶级AI芯片，已经运到了中国。"
2. **短句推进**：开头用短句，制造节奏感。
3. **预告利益**：让读者知道"这事跟我有关"。
   - "这事跟你有关——芯片进不来，算力成本就要涨，你用的AI工具迟早涨价。"

### 反面清单

- 长篇导入（"随着""近年来""众所周知"）
- 报菜名式罗列（一上来堆人名/参数）
- 没直击痛点或冲突就进入正文

## 四、结构通用模板

内容结构决定消费率。所有平台通用的一条主线原则：**一篇文章/一条视频只讲一件事，观点鲜明。**

### 通用叙事线

```
钩子（结果/冲突前置）
  → 证据（具体案例/数据，支撑观点）
  → 高潮（每3-4段/每30-40秒一个记忆点）
  → 观点（鲜明立场，不和稀泥）
  → 互动钩子（具体开放性问题）
```

### 结构三查

1. 有没有一条主线？（别多条线交叉）
2. 有没有高潮/记忆点？（没有=平，没人看完）
3. 观点鲜明吗？（"两面说"=没有观点=没有传播力）

## 五、互动钩子通用设计

互动率是各平台的共同权重。但互动不是自然发生的，是**设计**出来的。

### 互动钩子三原则

1. **具体**：问具体场景，不问抽象问题。"你觉得呢"不算，是废话。
2. **好回答**：让用户一句话就能答，降低参与门槛。
3. **有立场**：给出你的观点，让人想反驳或附和。

### 示例

- 差的："大家怎么看？" / "你觉得呢？"
- 好的："如果AI工具真的涨价30%，你是继续用还是找平替？" / "你公司或你身边的AI使用成本，最近涨了吗？"

### 发布后动作（通用）

- 前1小时回复所有评论（算法/平台都奖励作者互动）
- 挑有价值的评论做"置顶/追加回复"，引导二次讨论

## 六、关键词与搜索布局通用原则

搜索是各平台的长期流量来源。通用原则：

1. **核心词埋进标题前部**——让搜索引擎和用户都一眼看到
2. **长尾词自然分布正文**——不要堆砌，自然出现
3. **一内容一词**——每条内容主打一个搜索意图，别贪多

**示例**：标题"为什么宁可坐牢也要把B300这种顶级AI芯片运进中国？"——"顶级AI芯片"是大众搜索词，比裸用型号"B300"更易被搜到。

## 七、爆款拆解维度（通用）

迭代赢家的基础。任何平台的爆款都按这6个维度拆：

```
1. 钩子类型    → 数字反差/冲突/身份共鸣/威胁机会/疑问
2. 开头结构    → 结果前置/短句/利益预告
3. 选题角度    → 行业视角还是普通人视角？（普通人视角通常更通用）
4. 标题/开场公式 → 套哪个公式
5. 长度        → 该平台的合理区间
6. 发布时间    → 该平台的最佳时段
```

**一次只改一个维度**——同时改两个，你永远不知道哪个起作用。

## 八、通用红线（各平台共通底线）

各平台红线细节不同（见平台模块），但底线共通：

- **不标题党**：承诺必须兑现
- **不导流外链**：不引导到站外（微信/QQ等）
- **不洗稿抄袭**：原创度是账号生命线
- **不纯AI直发**：必须人工改写开头+加个人观点
- **不碰敏感话题**：时政、违法边界保持客观中立
