# 抖音口播平台模块 · douyin.md

> 抖音口播（知识类/口播类短视频）。这是流量教练的抖音"专业手册"。
> **数据基准：2026年8月（2026年4-6月算法底层重构后），会过期，每季度复核。**
> **重大前提：2026年抖音算法已从"完播率至上"转向"价值匹配"——收藏率/复访/铁粉成为核心。用老思路（死磕完播）做2026年的抖音会失效。**

---

## 零、先记住2026算法重构的3个颠覆（决定一切）

1. **权重彻底换序**：收藏率 > 复访率 > 铁粉互动 > 5秒完播 > 整体完播 > 评论质量 > 点赞 > 转发。完播率不再是王者，**收藏率登顶**（约40%权重）。
2. **搜索流量占比超50%**：视频前5秒要亲口说出核心关键词，否则搜不到你。
3. **推流周期拉长**：前3天数据平平不等于凉，4-7天收藏/复访/高质量评论回流仍会触发二次推流。

含义一句话：**别追求"让人看完"，追求"让人看完想收藏、想回看、想再来"。** 干货清单、模板、可带走的东西，比单纯讲得久更值钱。

## 一、抖音口播漏斗（层级B）

```
曝光（流量池分发）         推给多少人
 ↓
消费（3秒留存→5秒完播→整体完播）  留下并看完
 ↓
互动（收藏/复访/铁粉互动 > 点赞/转发）  值得回看和带走
 ↓
主页访问                    看完去看主页
 ↓
关注                       决定关注
 ↓
留存（铁粉/粉丝团）          回来复访
```

### 各层漏损症状与策略

| 漏损层 | 症状 | 策略重心 |
|--------|------|---------|
| 曝光低 | 播放量上不去 | 前5秒关键词（搜索）、话题标签、发布时段；查是否限流 |
| 消费低 | 3秒/5秒流失严重 | 前3秒钩子（冲突/反差/痛点）；节奏太慢 |
| 互动低（收藏少） | 看完不收藏不互动 | 内容没给"可带走的东西"——加清单/模板/步骤；这是2026第一权重 |
| 主页访问低 | 有人看完不点主页 | 没给"认识作者"的理由；人设弱 |
| 关注低 | 看了主页不关注 | 主页简介、置顶、连续内容承诺（追更理由） |
| 留存低 | 关注了不来复访 | 铁粉互动少、内容不连续、无固定栏目 |

### 抖音特有注意
- **铁粉互动**是2026新权重：回复评论区、让粉丝有归属感，比涨路人粉更值钱
- **复访率**：主页可回访性、系列内容（"明天继续讲"）驱动
- 点赞/转发已掉到最后——不要为了求赞做内容，要为收藏和复访做内容

## 二、口播判级标准（8项清单 · 抖音版）

配合通用层8项清单（SKILL.md 第五节），这里给抖音的数值和特有点。

| # | 检查项 | 抖音标准 | 决定什么 |
|---|--------|---------|---------|
| 1 | 开场钩子（前3秒） | 无冲突/反差/痛点/悬念/反问 → 不过；第一句说人话不铺垫不自我介绍 | 3秒留存 |
| 2 | 前5秒 | 必须亲口说出核心关键词（搜索流量>50%）；无开场画面强钩子 → 不过 | 搜索+5秒完播 |
| 3 | 结构 | 无主线/无信息点递进/一个视频讲多个点 → 不过；每5秒一个信息点 | 整体完播 |
| 4 | 长度 | 口播30-60秒完播最高；1分钟≈300字；宁短勿长，能少一秒是一秒 | 完播 |
| 5 | 互动/收藏钩子 | 结尾无"可带走的东西"（清单/模板/步骤）或行动引导 → 不过 | 收藏率（第一权重） |
| 6 | 关键词 | 前5秒口播核心词；标题/话题带关键词 | 搜索流量 |
| 7 | 红线 | 违禁词/导流/极限词/搬运（见第五节红线明细） | 账号生死 |
| 8 | 垂直一致 | 和账号定位领域不符 → 不过 | 账号权重 |

### 判级规则
- ✅可发：8项全过
- ⚠️小改：只有开场钩子或前5秒不过
- 🔧中改：结构/长度/节奏有硬伤
- ❌别发：有红线一票否决

### 口播脚本黄金结构（可直接套用）

```
前3秒 钩子：抛痛点/结论/悬念/反差/反问（第一句说人话）
 ↓
5-15秒 价值1：一个信息点（问题—方法—例子）
 ↓
每5秒一个信息点，层层递进，只讲一个核心点
 ↓
结尾 可带走+行动：给清单/模板/步骤（值得收藏）+ 引导关注/回看
```

**质量铁律**：
- 一个视频只讲一个点，讲深不讲多
- 口语化、短句、无书面废话；句长9-22字最顺耳
- 0-5秒放最有冲突/争议的画面和话（暴击开场）

## 三、单篇决策树阈值（层级A）

配合通用决策树（SKILL.md 第六节），抖音阈值如下：

| 决策点 | 抖音健康线 | 不达标定位 |
|--------|-----------|-----------|
| Q1 播放过低 | 几百都难破 | 账号权重低/被限流/标签乱/无关键词 |
| Q2 3秒/5秒留存低 | 5秒留存明显偏低 | 开场钩子问题 |
| Q3 整体完播低 | 口播类目标较高 | 结构/长度/节奏问题 |
| Q4 收藏率低 | 2026第一权重，明显低于互动基线 | 内容没给"可带走的东西" |
| Q5 指标达标但播放上不去 | — | 账号标签/垂直度问题 |
| Q6 播放停得早/无长尾 | — | 无搜索关键词（前5秒没说） |

> 注：抖音具体数值（收藏率健康线、5秒留存线）**待核验**——行业口径不一，标注为"参考区间"而非精确值。判断以"相对自身基线"为主。

## 四、抖音算法数据基准（2026重构后，会过期）

### 4.1 权重排序（多来源交叉验证）

| 排序 | 指标 | 说明 |
|------|------|------|
| 1 | 收藏率 | 登顶成为第一权重（约40%）——内容"值得反复看" |
| 2 | 复访率 | 用户会不会回来——系列/栏目化 |
| 3 | 铁粉互动 | 忠实粉丝互动——经营铁粉比求路人点赞有用 |
| 4 | 5秒完播率 | 开场钩子质量 |
| 5 | 整体完播率 | 已不再是核心前三 |
| 6 | 评论质量 | 高质量评论（非水评论） |
| 最后 | 点赞/转发 | 权重已跌至末位 |

### 4.2 关键机制

- **搜索流量占比 >50%**：前5秒亲口说出核心关键词；标题/话题/字幕都带词
- **推流周期拉长**：发布后4-7天内收藏/复访回流仍触发二次推流，前3天数据平平不等于凉
- **完播率门槛**：内容完播突破40%自动进入更高层级流量池（较早来源，5月说法；6月后权重重排）
- **标签弱化，AI行为预测推流**：不再靠传统标签，靠用户行为预测
- **算法从"猜你喜欢"变"算你会喜欢"**：看的是"值不值得反复看"，不是"看了多久"

### 4.3 口播时长标准

| 时长 | 适用 | 字数参考 |
|------|------|---------|
| 15秒 | 单一信息点/情绪共鸣 | 45-55字 |
| 30-60秒 | 口播主推，完播率最高 | 1分钟≈300字 |
| 60秒+ | 完整叙事（需强节奏，慎用） | 可承载完整故事 |

### 4.4 最佳发布时间

**待核验**：抖音黄金时段行业口径为早7-9、午12-13、晚19-22（通勤/午休/睡前），但2026算法重构后发布时段影响下降（推流周期拉长）。**以账号自身实测为准**，建议记录各时段发布数据对比。不硬给精确值。

## 五、抖音口播红线

| 红线 | 处罚 |
|------|------|
| 绝对化宣传词（最/第一/唯一） | 限流/降权 |
| 效果承诺词（"用了就涨粉"） | 限流/下架 |
| 稀缺逼单话术（"最后几单""仅此一天"） | 限流（电商类） |
| 站外导流（手机号/微信/二维码/引导加微信，文字口播画面私信都不行） | 第一次关闭橱窗7天，第二次永久收回+冻结佣金 |
| 搬运/抄袭素材 | 限流/下架 |
| 诱导点赞互关 | 隐性限流 |
| 乱蹭无关热门话题 | 隐性限流 |
| 画面出现门店地址/私人手机号 | 风控限流 |

**隐形限流特别提示**：很多违规不弹窗提醒，直接悄悄压作品质量。口播用词、字幕极限词、不经意搬运、诱导互关、乱蹭话题，全算隐性违规。判断"是不是被隐形限流"：查作品是否播放断崖式下跌且无处罚通知。

**AI内容红线**：AI口播脚本需人工改写，加个人观点和口播化改写，避免纯AI文案的书面感（平台有AIGC检测）。

## 六、抖音口播发布节奏

- **新号**：每天1条，垂直度优先，前30天做数据实验
- **稳定期**：每周3-5条精品 + 评论区互动运营（铁粉互动是权重）
- **复盘**：24-48小时看数据 → 第7天看二次推流/长尾 → 周日周复盘
- **系列化**：固定栏目/系列（复访率权重），"明天继续讲"留钩子

## 七、口播脚本实战模板（可直接套用）

### 模板A：30-60秒干货口播（推荐）

```
【0-3秒 钩子】"99%的人做口播，第一句话就劝退了观众。"（反差点名）
【3-8秒 痛点】"一开口就自我介绍'我是谁谁谁'，观众直接划走。"（痛点+前5秒关键词：口播/划走）
【8-40秒 价值】一个点讲透：不自我介绍，第一句抛结论/痛点/悬念。每5秒一个信息点，短句。
【40-55秒 可带走】"记住口诀：第一句说人话，别铺垫。"（让观众想收藏）
【55-60秒 行动】"我主页还有整套口播结构，关注回看。明天讲怎么搭钩子。"（复访+铁粉）
```

### 模板B：清单/盘点型（收藏驱动，2026最吃香）

```
【钩子】"做口播最容易踩的3个坑，最后一个你天天犯。"
【价值】3个坑逐一讲，每个配反例+正例
【可带走】"把这3条收藏，开拍前对照一遍。"
【行动】"关注我，下一期讲怎么改。"
```

### 质量自检（发布前）

1. 前3秒不划走？（冲突/反差/痛点）
2. 前5秒说了关键词吗？（搜索）
3. 一个视频一个点吗？
4. 结尾有"可带走的东西"吗？（收藏）
5. 有违禁词/导流吗？
