## 一、头条漏斗（层级B）

```
曝光 (impressions)          算法给了多少展现
 ↓
消费 (CTR × 完读)           点开并读完
 ↓
主页访问 (profile visit)    读完去看主页
 ↓
关注 (follow)               决定关注
 ↓
留存 (retention)            关注后留下/掉粉
```

### 各层漏损症状与策略

| 漏损层 | 症状 | 策略重心 |
|--------|------|---------|
| 曝光低 | 好文章也没人看到 | 分发：钩子、话题标签、发布时间；查是否被限流 |
| 消费低 | 曝光高但CTR/完读低 | 钩子层：标题、封面、开头第一屏 |
| 主页访问低 | 有人读但没人想看作者 | 内容没给"认识作者"的理由；作者价值信号弱 |
| 关注低 | 访问了主页但走人 | 主页：简介、置顶、时间线一致性，没承诺未来价值 |
| 留存低 | 关注了又掉粉/死粉 | 内容一致性、人设与受众匹配、过度依赖单篇爆款 |

### 头条特有注意
- 头条是**算法推荐 + 搜索**双通道，搜索占比在上升（见数据基准）
- 微头条走轻量消费，长文走深度消费，两个池子不完全互通

## 二、头条判级标准（审核8项清单 · 数值标准）

配合通用层8项清单（SKILL.md 第五节）使用，这里给头条的数值和特有点。

| # | 检查项 | 头条标准 | 决定什么 |
|---|--------|---------|---------|
| 1 | 标题 | ≤30字；前23字含核心关键词；有数字/冲突/悬念；无夸张词 | 点击率 |
| 2 | 开头3段 | 无钩子/长篇导入/没直击痛点 → 不过 | 完读率 |
| 3 | 结构 | 无主线/长段落无高潮/观点中立"两面说" → 不过 | 完读率 |
| 4 | 长度 | 图文1500-2500字最佳；微头条200-400字 | 完读率 |
| 5 | 互动钩子 | 结尾无具体开放性问题 → 不过（"你觉得呢"不算） | 互动率 |
| 6 | 关键词 | 标题前部埋核心词；正文自然分布长尾词 | 搜索流量 |
| 7 | 红线 | 标题党/导流/洗稿/敏感/AI未标注（见第五节红线明细） | 账号生死 |
| 8 | 垂直一致 | 和账号定位领域不符 → 不过 | 账号权重 |

### 判级规则
- ✅可发：8项全过
- ⚠️小改：只有标题或开头不过
- 🔧中改：结构/长度/钩子有硬伤
- ❌别发：有红线一票否决

## 三、头条单篇决策树阈值（层级A）

配合通用决策树（SKILL.md 第六节），头条阈值如下：

| 决策点 | 头条健康线 | 不达标定位 |
|--------|-----------|-----------|
| Q1 展现过低 | <500 | 账号权重低/被限流/标签乱 |
| Q2 点击率低 | <5% | 标题/封面问题 |
| Q3 完读率低 | <30% | 开头/长度/节奏问题 |
| Q4 互动率低 | <5% | 内容没讨论价值 |
| Q5 指标达标但展现上不去 | — | 账号标签/垂直度问题 |
| Q6 爆发后很快停 | — | 无搜索关键词布局 |

> **样本要求**：单篇数据只给方向；下诊断至少看同类型3-5篇平均，或提供该篇与账号均值的对比。

### 头条背离诊断（哪两个指标打架，一眼定位）

| 背离组合 | 头条对应 | 定位 |
|---------|---------|------|
| 曝光高 + 点击率低 | 展现多但CTR<5% | 标题/封面问题 |
| 点击高 + 完读低 | CTR≥5%但完读<30% | 开头3段/结构/长度问题 |
| 完读高 + 互动低 | 完读≥50%但互动<5% | 选题没共鸣，无讨论价值 |
| 互动高 + 关注低 | 评论多但不涨粉 | 受众不匹配/主页无转化 |

## 三·五、头条平台的利益逻辑（为什么算法长这样）

头条算法不是"公平考试"，是平台的算盘：

- **完读率升为第一权重（35%）**——完读=用户时长=广告曝光收益，头条靠广告变现，用户读得久平台才赚钱。所以它奖励"能让人读完"的内容，惩罚标题党（点了就走伤用户信任）。
- **搜索占比从15%升到24%**——搜索是"用户主动来"，比被动推荐更精准，广告价值更高。所以平台在引导创作者布局搜索词。
- **垂直度加权（≥80%享+30%）**——垂直账号用户留存高、广告主愿意定向投，平台奖励垂直。

**理解这三点，你就知道头条算法往哪变**：持续奖励"高完读+垂直+搜索"的内容。别跟平台利益对着干（比如靠标题党骗点击）——那是在跟平台的钱包作对。

## 四、头条算法数据基准（会过期）

### 4.1 算法权重（2026年8月新版）

| 指标 | 权重 | 说明 |
|------|------|------|
| 完读率 | 35% | 第一权重，较旧版提升40% |
| 点击率（CTR） | 25% | 决定是否进入下一级流量池 |
| 互动率 | 20% | 点赞+评论+转发+收藏 |
| 搜索流量 | 24% | 较旧版提升60%（从15%→24%） |
| 作者回复率 | 8% | 计入推荐权重（互动相关） |

**核心变化**：完读率从"参考指标"升级为"核心权重指标"，标题党打法失效，垂直深耕+长尾搜索崛起。

### 4.2 流量池递进机制

| 层级 | 规模 | 进入条件 |
|------|------|---------|
| 冷启动池 | 500-1000次展现 | 发布即进入，审核消重后 |
| 中级流量池 | 1-10万人 | 点击率≥5% 且 完读率≥30% |
| 高级流量池 | 10万+（全网推荐） | 持续表现好 |
| 长尾流量 | 持续3-6个月 | 命中搜索关键词 |

**数据支撑**：完读率从30%→60%，推荐量增2.8倍；完读率>70%，进入二级流量池概率提升4.5倍。

### 4.3 爆款内容标准

| 指标 | 健康线 | 爆款线 |
|------|--------|--------|
| 完读率 | ≥50% | >55% |
| 平均阅读时长 | >1分20秒 | — |
| 评论区互动率 | ≥8% | — |
| 点击率（CTR） | ≥5% | — |
| 粉丝转化率 | ≥1% | — |
| 账号垂直度 | ≥80%享受领域加权+30% | — |
| 垂直度60-80% | 基础推荐 | — |
| 垂直度<60% | 推荐量-20%，不进领域池 | — |

## 五、头条红线（违规信用分）

| 违规行为 | 处罚 |
|---------|------|
| 标题党（夸张词汇过多） | 扣20分信用分 |
| 导流到微信/QQ等外部平台 | 扣20分 |
| 配图带联系方式 | 扣20分 |
| 抄袭洗稿 | 限流+扣分，严重者封号 |
| AI生成内容未标注 | 限流 |
| 信用分扣到0 | 封号 |

**AI内容红线**：第三代AI原创识别系统，纯AI直发100%限流。要求"AI出稿80%+人工改写20%"，开头100字人工写、加个人案例、原创度>60%再发。

## 六、头条发布节奏

- **新号**：每天1-2篇（图文）+ 微头条2-3条，保持活跃但不刷屏
- **稳定期**：每周3-5篇精品图文 + 每日微头条
- **复盘**：单篇1小时看初始 → 3小时看推荐趋势 → 7天看长尾；周日周复盘

## 七、头条实战案例（已验证模式）

### 案例A：AI裁员话题（2026-06，账号"兔仙人说AI"）
- 标题：《当AI成为裁员理由:15万人失业背后，谁在被重新定价》
- 模式：数字反差 + 普通人利益（职场人怕被裁）→ 行业新闻 × 职场视角
- 验证结论：**"行业事件 → 普通人利益"是AI领域的高转化结构**

### 案例B：行业新闻翻译成职场价值
- 原视角："GLM-5.3性能追平Claude，价格1/40"（从业者视角）
- 翻译后："GLM-5.3便宜40倍，对你意味着什么：你的AI工具会降价，但这几种岗位会更贵"（职场人视角）
- 验证结论：行业视角吸引从业者，职场视角吸引目标受众（账号定位人群）

### 案例C：B300走私案（2026-08，审核判级 ✅可发）
- 亮点句："这事跟你有关——芯片进不来，算力成本就要涨，你用的AI工具迟早涨价"
- 验证结论：钩子+利益预告+互动钩子（"AI涨价30%你用还是找平替"）三件套齐全
